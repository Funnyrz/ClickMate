## ClickMate 1.3.6 (12)

### 安装说明 / Installation

下载 `ClickMate-1.3.6-universal-unsigned.dmg`，打开后将 **ClickMate.app** 拖入 **Applications（应用程序）**。打开“终端”执行以下命令，然后打开应用：

Download the DMG and drag **ClickMate.app** into **Applications**. Run this command in Terminal, then open the installed app:

```sh
xattr -dr com.apple.quarantine /Applications/ClickMate.app
```

该命令移除下载应用的隔离属性；文件夹访问、辅助功能和屏幕录制等权限仍需按使用的功能分别授权。

The command removes the downloaded app’s quarantine attribute. Grant folder access, Accessibility, and Screen Recording separately for the features you use.

本安装包不使用开发者证书签名，未经 Apple 公证，仅使用本地 ad-hoc 签名。升级后 macOS 可能要求重新授权。无 App Group 时，明确选择的监控目录通过本机备用通道同步；其他 Finder 配置和共享运行状态仍受限制。后台快捷服务在当前登录会话中运行，注销或重启后需重新打开 ClickMate。

This package uses local ad-hoc signing without a developer certificate or Apple notarization. macOS may request permissions again after upgrading. Explicitly selected monitoring folders sync through a local fallback when App Group is unavailable; other Finder settings and shared runtime status remain limited. Reopen ClickMate after logout or restart to run the session-only shortcut service.

### 中文更新说明

- **修复菜单显示但命令无响应**：保留 Finder 菜单创建时的操作与选择上下文，修复新建文件、复制文件名和计算哈希等命令的派发，并打开当前安装的主应用处理操作。
- **改善首次安装目录覆盖**：扩展启动时立即注册默认安全目录，避免目录访问检查阻塞基础菜单。
- **支持外置盘重定向目录**：桌面、下载等目录重定向到外置盘时，可在权限页明确选择实际目录；不自动监控整个外置盘。
- **无 App Group 也可同步所选目录**：通过本机备用通道同步监控路径，扩展缓存已选目录，并同步移除操作；目录授权书签保留在主应用中。
- **更准确的权限状态**：分别显示扩展启用、目录监控、共享通道和真实文件操作结果。完全磁盘访问显示为“系统管理／未验证”，操作成功仅验证对应目录。
- **改进恢复与诊断**：匹配当前安装路径的扩展登记，修复失败恢复无法再次执行的问题，并补充 Finder 菜单诊断脚本。
- **保持安装包命名与拖动安装**：保留 ClickMate 卷名、ClickMate.app 和 Applications 链接，文件名不再附加内部构建号。

### English release notes

- **Fix visible menus with unresponsive commands:** retain the action and selection captured when Finder creates a menu, and route file creation, filename copying, and hashing to the currently installed app.
- **Improve first-install coverage:** register default safe folders immediately, without waiting for filesystem access checks.
- **Support redirected external folders:** explicitly select the actual target when folders such as Downloads reside on an external volume, without monitoring the whole volume automatically.
- **Sync selected folders without App Group:** use a local fallback for monitoring paths, retain an extension cache, and propagate removals. Authorization bookmarks remain in the main app.
- **Report permission evidence accurately:** distinguish extension enablement, monitoring, shared communication, and actual file operation results. Full Disk Access remains system-managed and unverified; successful operations verify only their target directory.
- **Improve recovery and diagnostics:** match extension registrations to the current installation, allow bounded retries after failed recovery, and add a Finder menu diagnostic script.
- **Keep consistent DMG naming and installation:** retain the ClickMate volume, ClickMate.app, and Applications link; omit the internal build number from the filename.
