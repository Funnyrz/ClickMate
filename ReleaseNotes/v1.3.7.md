## ClickMate 1.3.7 (14)

### 安装说明 / Installation

下载 `ClickMate-1.3.7-universal-unsigned.dmg`，打开后将 **ClickMate.app** 拖入 **Applications（应用程序）**。打开“终端”执行以下命令，然后打开应用：

Download the DMG and drag **ClickMate.app** into **Applications**. Run this command in Terminal, then open the installed app:

```sh
xattr -dr com.apple.quarantine /Applications/ClickMate.app
```

该命令移除下载应用的隔离属性；文件夹访问、辅助功能和屏幕录制等权限仍需按使用的功能分别授权。

The command removes the downloaded app’s quarantine attribute. Grant folder access, Accessibility, and Screen Recording separately for the features you use.

本安装包不使用开发者证书签名，未经 Apple 公证，仅使用本地 ad-hoc 签名。升级后 macOS 可能要求重新授权。无 App Group 时，明确选择的监控目录通过本机备用通道同步；其他 Finder 配置和共享运行状态仍受限制。后台快捷服务在当前登录会话中运行，注销或重启后需重新打开 ClickMate。

This package uses local ad-hoc signing without a developer certificate or Apple notarization. macOS may request permissions again after upgrading. Explicitly selected monitoring folders sync through a local fallback when App Group is unavailable; other Finder settings and shared runtime status remain limited. Reopen ClickMate after logout or restart to run the session-only shortcut service.

### 中文更新说明

- **恢复退出后的后台截图**：空闲时一次 ⌘Q 即可退出设置程序并移除 Dock 运行图标，Helper 保持独立运行；有未保存编辑或文件任务时安全完成退出流程。
- **修复连续滚动时长截图不拼接**：改为单个串行采样循环，保留中间帧；鼠标、触控板或拖动滚动条时均能检查画面变化，静止画面不会误触发完成。
- **保护长截图目标和已采集内容**：恢复目标应用后再采集首帧，切换应用时单独暂停；暂停、取消和完成后丢弃晚到帧，系统捕获回调停滞时仍能导出已拼接内容。

### English release notes

- **Restore screenshots after quitting:** an idle ⌘Q exits the settings app and removes its running Dock icon while the independent Helper stays available. Unsaved archive edits and running file tasks still finish the quit flow safely.
- **Fix scrolling capture during continuous scrolling:** use one serial sampling loop to preserve intermediate frames. Mouse, trackpad, and scrollbar scrolling are observed; idle frames no longer finish capture automatically.
- **Protect the target and captured content:** restore the target app before the first frame and pause separately when the active app changes. Discard late frames after pause, cancellation, or completion; export committed content even if a screen-capture callback stalls.
