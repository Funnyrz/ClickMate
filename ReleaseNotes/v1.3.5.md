## ClickMate 1.3.5 (10)

> [!WARNING]
> 本次安装包未经 Developer ID 签名和 Apple 公证，采用临时 ad-hoc 签名。App Group 配置同步、共享运行状态和自动权限验证不可用；部分 Finder 操作使用 URL 降级路径。升级后可能需要重新授予辅助功能、屏幕录制和磁盘访问权限。后台快捷服务仅在当前登录会话中运行，注销或重启后需重新打开 ClickMate。
>
> This package is ad-hoc signed, without Developer ID signing or Apple notarization. App Group settings synchronization, shared runtime status, and automatic permission verification are unavailable; some Finder actions use the URL fallback. Upgrading may require granting Accessibility, Screen Recording, and disk access again. The shortcut service runs only in the current login session; reopen ClickMate after logout or restart.

### 中文更新说明

- **保护压缩包编辑内容**：切换条目、打开其他压缩包、关闭窗口和退出应用时统一处理未保存修改；保存失败或取消签名提醒时保留编辑内容。
- **真实 ZIP 与正确的 Finder 操作**：后台生成并验证 ZIP，支持同目录多选、文件夹递归和符号链接；修正空白区域菜单的选择语义，制作系统可识别的 Finder 替身。
- **后台文件任务**：哈希采用增量分块读取，支持进度和取消；压缩、复制、制作替身及移动显示逐项结果，不依赖系统通知查看任务。
- **移动恢复**：本次应用会话内可恢复成功移动的项目，检查文件变化和原位置冲突，跳过冲突项目并禁止覆盖。
- **更可靠的长截图**：分离捕获异常和无重叠计数，连续两次无重叠后暂停，已拼接内容仍可完成并导出。
- **完整模板编辑**：编辑名称、默认文件名、扩展名和文本内容，支持复制内置模板及无扩展名文件；取消编辑不改变原值。
- **按功能设置权限**：分别引导 Finder 工具、访达剪切和截图，区分权限状态与试用结果，保留详细诊断。
- **配置备份与迁移**：新增版本化 JSON 导入导出、变更预览、有效配置备份和损坏恢复；不迁移系统权限或目录授权书签。
- **更流畅的设置页**：语言文案改为内存读取，快捷功能和权限页后台刷新状态，合并快速切换时的重复请求。
- **完整中英文文档**：重写 README，更新 24 张使用演示数据的原生界面配图，并提供可重复生成、隐私脱敏和元数据检查流程。

### English release notes

- **Protect archive edits:** handle unsaved changes consistently when switching entries, opening another archive, closing the window, or quitting. Failed saves and cancelled signature warnings retain the draft.
- **Real ZIP archives and correct Finder actions:** create and verify ZIPs in the background, including same-folder selections, recursive folders, and symbolic links. Correct background-menu selection rules and create genuine Finder aliases.
- **Background file tasks:** stream hashes incrementally with progress and cancellation. Compression, duplication, aliases, and moves show per-item results that remain accessible without notifications.
- **Restore moved items:** restore successful moves during the current app session. Changed files and occupied original locations are skipped without overwriting.
- **More reliable scrolling capture:** track capture failures separately from overlap failures. Two consecutive overlap failures pause capture while retaining stitched content for export.
- **Complete template editing:** edit names, default filenames, extensions, and text; duplicate built-in templates and create extensionless files. Cancelling preserves saved values.
- **Feature-based permission setup:** guide Finder tools, Finder Cut, and screenshots separately, distinguish permission readiness from trial results, and retain detailed diagnostics.
- **Settings backup and transfer:** add versioned JSON import/export, change previews, valid configuration backups, and corruption recovery. System permissions and folder authorization bookmarks are not transferred.
- **Smoother settings tabs:** read language preferences from memory and refresh Quick Features and Permissions statuses in the background, coalescing duplicate requests during rapid switching.
- **Updated bilingual documentation:** rewrite both READMEs and replace the illustrations with 24 native demo captures, including repeatable generation, privacy redaction, and metadata checks.
